# Advanced DevOps Project - Rishi Kumar

## Project Overview
This project demonstrates a complete DevOps lifecycle including Version Control, Dockerization, and Multi-container Orchestration.

## Tech Stack
- **Frontend:** Nginx (Port 80)
- **Backend:** Node.js with Express (Port 3000)
- **Containerization:** Docker & Docker Compose

## How to Run
1. Clone the repo: `git clone https://github.com/RISHIKUMAR206/advanced-devops-project.git`
2. Start containers: `docker compose up -d`
3. Access Frontend: `http://localhost`
4. Access Backend: `http://localhost:3000`

## Project Parts
- **Part 1 & 2:** Git Branching and Tagging.
- **Part 3:** Multi-container setup using Docker Compose.
- **Part 4:** Monitoring logs and Cleanup (`docker compose down`).
